1 제품 개요

myFinger SDK는 스마트폰 후면 카메라만으로 지문 인증을 구현하는 모바일 SDK입니다. 별도 지문 센서(하드웨어) 없이 iOS · Android 앱에 통합할 수 있으며, 생체 데이터 처리는 기기 내부에서 완결됩니다.

특징설명
카메라 기반 지문 인식일반 후면 카메라로 지문 촬영 및 특징점 추출
온디바이스 처리지문 원본 이미지 및 특징점이 기기 외부로 전송되지 않음
크로스 플랫폼iOS (Swift), Android (Kotlin) 동일한 API 구조 제공
라이선스 기반키 발급 후 앱에서 초기화, 만료 기반 접근 제어

2 기술 사양

2.1 플랫폼 지원

플랫폼최소 버전개발 언어배포 형태
iOSiOS 17.0Swift 5.9+XCFramework
AndroidAPI 26 (Android 8.0)Kotlin 1.9+AAR
iOS: arm64 실기기 전용. 시뮬레이터 미지원.

2.2 성능 지표

항목수치
특징점 추출 속도~70ms (실기기 기준)
최소 특징점 개수6개 이상 (인증 신뢰도 보장 기준)
권장 품질 점수40점 이상 (0–100 스케일)
인증 세션 유효시간5분

2.3 특징점 데이터 규격

항목규격
버퍼 크기4,096 바이트 고정
데이터 형식바이너리 (플랫폼 비종속)
원본 이미지 포함 여부포함되지 않음
역변환(지문 복원) 가능 여부불가

3 보안 설계

3.1 온디바이스 처리 원칙

[카메라 촬영]
     ↓
[기기 내: 이미지 처리 → 특징점 추출 → 로컬 매칭]
     ↓
[결과(true/false)만 앱으로 반환]

※ 지문 이미지 및 특징점 원본은 기기 외부로 전송되지 않습니다.

3.2 특징점 저장 권고사항

SDK는 특징점 추출 결과를 앱에 반환합니다. 생체정보는 민감 개인정보이므로 저장 방식에 따라 아래 기준을 준수하시기 바랍니다.

사용 시나리오권고 조치
인메모리 임시 매칭 (저장 없음)별도 암호화 불필요 — 매칭 후 즉시 메모리에서 해제
기기 내 영구 저장 (로컬 DB, SharedPreferences 등)AES-256-GCM 암호화 필수, Android Keystore / iOS Keychain 키 보호 권장
서버 전송 또는 외부 저장AES-256 암호화 후 TLS 1.2 이상으로 전송, 서버 측 접근 제어 적용
⚠️ 백업 유출 주의: 기기 내 저장 시에도 OS 백업(Android ADB Backup, iCloud Backup)을 통해 특징점이 유출될 수 있습니다.
Android: backup_rules.xml로 특징점 파일 백업 제외, iOS: NSFileProtectionComplete 속성 적용을 권장합니다.

3.3 라이선스 검증 방식

  • 앱 최초 실행 시 라이선스 서버에 1회 연결하여 유효성 검증
  • 이후 동일 세션에서는 캐시 사용 (네트워크 불필요)
  • 오프라인 정책: 네트워크 오류 시 SDK 사용 허용. 라이선스 키 자체가 유효하지 않은 경우만 차단.

3.4 개인정보 처리

항목처리 방식
지문 원본 이미지처리 후 즉시 메모리에서 삭제, 저장 없음
특징점 데이터앱이 명시적으로 저장하지 않으면 영구 보존 없음
서버 전송SDK 자체는 생체 데이터를 서버로 전송하지 않음
사용 로그라이선스 검증 요청만 서버에 기록 (생체 정보 미포함)

등록 · 인증 흐름 요약

단계등록 (Enrollment)인증 (Verification)
1카메라로 지문 3회 촬영카메라로 지문 1회 촬영
2SDK가 각 촬영에서 특징점 추출SDK가 특징점 추출
3앱이 특징점(4,096 bytes × 최대 3개) 저장저장된 특징점과 1:N 비교
4—매칭 결과(성공/실패) 반환

5 SDK 공개 API 요약

iOS (Swift)

// 라이선스 초기화
DiFingerSDK.shared.initialize(licenseKey:) async -> Result<LicenseInfo, LicenseError>

// 캡처 화면 (SwiftUI Sheet)
DiFingerCaptureView(mode: DiFingerSessionMode) { result: CaptureSessionResult in ... }
// mode: .registration (등록) | .verification (인증)

// 로컬 매칭
DiFingerSDK.shared.match(finger1: [UInt8], finger2: [UInt8]) async -> MatchResult

Android (Kotlin)

// 라이선스 초기화
LicenseManager.check(context, licenseKey) { result: LicenseResult -> ... }

// 캡처 화면 실행 (Activity Result)
FingerActivity.createIntent(context, isOriginFingerprint, fingerCount)

// 로컬 매칭
IzzixServiceProxy.matchMinutiae(reqFeatures, resFeatures, matchLevel): Boolean?
