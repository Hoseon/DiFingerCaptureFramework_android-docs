class FingerActivity : BaseActivity, Handler.Callback

지문 촬영 Activity.

DiFingerCapture SDK의 핵심 촬영 화면입니다. 카메라 미리보기 위에 AI 기반 손가락 감지, 품질 분석, 특징점 추출을 자동으로 수행하고 결과를 com.digentid.difingercapture.UseSharedPreference에 저장한 뒤 RESULT_OK로 종료합니다.

사용 예시

등록 (카드A, 3라운드)

val launcher = registerForActivityResult(StartActivityForResult()) { result ->
    if (result.resultCode == RESULT_OK) {
        val pref = UseSharedPreference(context)
        val rounds = pref.getLocalFingerprintARounds()  // List<ExtractResult>, 최대 3개
    }
}
launcher.launch(FingerActivity.createIntent(this, isOriginFingerprint = true))
