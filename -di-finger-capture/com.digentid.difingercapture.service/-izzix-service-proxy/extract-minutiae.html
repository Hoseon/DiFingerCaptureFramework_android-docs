extractMinutiae

fun extractMinutiae(bitmap: Bitmap, width: Int, height: Int, dpi: Int = 500, colorInversion: Int = 0, withThinned: Boolean = false): ExtractResult?

지문 비트맵에서 특징점을 추출합니다.

내부적으로 :izzix 별도 프로세스의 IzzixFCI JNI 엔진에 AIDL로 요청합니다. 프로세스 크래시 시 자동으로 1회 재연결 후 재시도합니다.

권장 이미지 규격

  • 크기: 256×360 픽셀

  • 형식: 그레이스케일 (ARGB_8888 Bitmap, 실제 채널은 동일 값)

  • 해상도: 500 DPI

  • 전처리: 방사왜곡 보정 → 원근 보정 → CLAHE → 언샤프 마스크 순서 적용 후 입력

Return

추출 성공 시 ExtractResult, 실패(서비스 연결 불가 또는 JNI 오류) 시 null.

Parameters

bitmap

전처리 완료된 지문 비트맵.

width

비트맵 너비 (픽셀). bitmap.width와 일치해야 합니다.

height

비트맵 높이 (픽셀). bitmap.height와 일치해야 합니다.

dpi

이미지 해상도 (기본값 500 DPI).

colorInversion

색상 반전 여부. 1 = 반전(밝은 배경에 어두운 지문 → 반전 권장), 0 = 정상.

withThinned

true이면 ExtractResult.thinnedBitmap에 세선화(thinning) 이미지도 포함.
