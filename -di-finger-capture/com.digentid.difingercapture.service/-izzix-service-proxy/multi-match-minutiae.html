multiMatchMinutiae

fun multiMatchMinutiae(reqFeaturesList: List<ByteArray>, resFeaturesList: List<ByteArray>, matchLevel: Int = 0, fingerCount: Int = 2): MultiMatchResult

등록 지문 세트와 인증 지문 세트의 모든 조합을 비교합니다 (iOS SDK multiMatch와 동일한 규칙).

2손가락 등록(3라운드 × 2손가락 = 6개)과 2손가락 인증(2개)이면 6 × 2 = 12쌍을 비교하며, 그중 1쌍이라도 매칭되면 MultiMatchResult.isMatch가 true 입니다. 1손가락(3개 × 1개)에도 그대로 쓸 수 있습니다.

val enrolled = pref.getLocalFingerprintAMultiSlots().map { it.features }   // 6개
val captured = pref.getLocalFingerprintBMulti().map { it.features }       // 2개
val result = IzzixServiceProxy.instance.multiMatchMinutiae(enrolled, captured, pref.getMatchLevel())
if (result.isMatch) { /* 동일인 */}

Parameters

reqFeaturesList

등록(기준) 특징점 목록. 2손가락 등록은 슬롯 순서(R1F1, R1F2, R2F1, R2F2, R3F1, R3F2)대로 전달합니다.

resFeaturesList

인증(비교) 특징점 목록. 2손가락 인증은 F1, F2 순서입니다.

matchLevel

보안 레벨 (0~5). com.digentid.difingercapture.UseSharedPreference.getMatchLevel 값을 권장합니다.

fingerCount

등록 세트의 라운드당 손가락 수 (기본 2). 결과의 reqRound / reqFinger 계산에만 쓰입니다.
